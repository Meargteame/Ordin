# Premium White Mode - World-Class UI Design

## Design Philosophy
**Inspired by:** Stripe Dashboard, Apple Design Awards, Figma, Linear
**Goal:** Premium, unique, worth paying for - NOT generic AI bloat

## Key Features

### 1. **Stunning Header with Mesh Gradient**
- 200px expandedHeight with stretch effect
- Multi-color gradient background (Indigo → Purple → Pink)
- Custom mesh gradient overlay (radial gradient effect)
- 36px bold greeting with -1.5 letter-spacing
- Circular progress ring with gradient stroke
- 3 metric chips with colored shadows

### 2. **Daily Overview Card**
- Gradient background (Indigo → Purple)
- Gradient icon button with shadow
- Motivational message
- Progress counter
- Premium borders and shadows

### 3. **Section Headers with Gradient Bars**
- 4px vertical gradient bar (unique identifier)
- Tasks: Indigo → Purple gradient
- Habits: Purple → Pink gradient
- Bold 24px headings with -0.8 letter-spacing
- Completion badges with colored backgrounds

### 4. **Premium Task/Habit Cards**
- 16px border radius (modern, not excessive)
- 1.5px borders (substantial, not thin)
- Gradient checkboxes when complete (Green gradient)
- Glowing shadows when complete
- Time badges with gradient backgrounds
- Fire streak badges with gradient (Orange → Red)
- Smooth hover states

### 5. **Typography System**
- **Display:** 36px/w800/-1.5 (Hero text)
- **Heading:** 24px/w800/-0.8 (Sections)
- **Body:** 16-17px/w600-w700/-0.2 to -0.3 (Content)
- **Caption:** 11-14px/w600-w700 (Labels)
- Tight letter-spacing for premium feel

### 6. **Color Palette**
```
Background: #FAFAFA (soft gray)
Surface: #FFFFFF (pure white)
Primary: #6366F1 (Indigo)
Secondary: #A855F7 (Purple)
Accent: #EC4899 (Pink)
Success: #10B981 (Green)
Warning: #F59E0B → #EF4444 (Orange to Red gradient)
Text Primary: #0F172A (Near black)
Text Secondary: #64748B (Slate)
Text Tertiary: #94A3B8 (Light slate)
Border: #E2E8F0 (Light gray)
```

### 7. **Gradient System**
- **Header:** Indigo → Purple → Pink (subtle, 5% opacity)
- **Progress Ring:** Indigo → Purple
- **Section Bars:** Indigo → Purple, Purple → Pink
- **Checkboxes:** Green → Dark Green
- **Streak Badges:** Orange → Red
- **Time Badges:** Indigo → Purple (10% opacity)

### 8. **Shadow System**
- **Subtle:** 0.03 opacity, 12px blur, 4px offset
- **Medium:** 0.08-0.1 opacity, 12-16px blur, 4-6px offset
- **Strong:** 0.15-0.3 opacity, 20px blur, 8px offset
- **Colored shadows** for completed items and badges

### 9. **Spacing System**
- Screen padding: 20px
- Card spacing: 12px between cards
- Section spacing: 24px between sections
- Internal padding: 18px (cards), 20px (overview)
- Metric chips: 10px gap

### 10. **Unique Elements**
✅ Mesh gradient overlay (custom painter)
✅ Circular progress with gradient stroke (custom painter)
✅ Vertical gradient bars for sections
✅ Gradient fire badges
✅ Colored metric chips with shadows
✅ Stretch effect on header
✅ Gradient backgrounds throughout

## What Makes This Premium

### Visual Hierarchy
- **Bold typography** (w800) for impact
- **Tight letter-spacing** for sophistication
- **Gradient accents** for depth
- **Colored shadows** for dimension
- **Mesh gradients** for richness

### Attention to Detail
- 1.5px borders (not 1px, not 2px)
- 16px radius (not 8px, not 24px)
- Custom painters for unique effects
- Gradient strokes on progress ring
- Colored shadows match element colors
- Smooth transitions and hover states

### Color Psychology
- **Indigo** = Trust, professionalism
- **Purple** = Creativity, premium
- **Pink** = Energy, modern
- **Green** = Success, completion
- **Orange/Red** = Motivation, fire

### Unique Personality
- NOT generic blue everywhere
- NOT excessive rounded corners
- NOT flat and boring
- NOT over-designed with decorations
- **Perfect balance** of premium + functional
