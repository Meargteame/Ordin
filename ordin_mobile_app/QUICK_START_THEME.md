# Quick Start: Testing Dark Mode

## Run the App
```bash
flutter run -d RZCX40NTHJD
```

## Test Theme Switching (3 Steps)

### Step 1: Navigate to Settings
1. Open the app
2. Tap **More** tab (bottom right)
3. Tap **Settings** (at the bottom of the list)

### Step 2: Switch Themes
In the Appearance section at the top, you'll see three theme buttons:
- **Light** - Clean white background with dark text
- **Dark** - Dim dark blue background (#0F1419) with light text
- **System** - Follows your device's theme setting

Tap any button to instantly switch themes!

### Step 3: Explore All Screens
Navigate through the app to see the theme in action:
- **Today** - Dashboard with stats and tasks
- **Tasks** - Task list with priorities
- **Habits** - Habit tracking with streaks
- **More** - All mini-apps

## What to Look For

### ✅ Light Mode
- Clean white cards on light gray background
- Dark text that's easy to read
- Subtle shadows on cards
- Professional blue accents

### ✅ Dark Mode (Dim Dark Blue)
- Dark blue-gray background (#0F1419)
- Slightly lighter cards (#1E2430)
- White text with good contrast
- Same blue accents
- **NOT pure black** - natural dim blue tone

## Theme Features

- ✅ **Instant switching** - No app restart needed
- ✅ **Persistent** - Theme stays when navigating
- ✅ **Natural dark mode** - Comfortable dim blue, not harsh black
- ✅ **System sync** - Can follow device theme
- ✅ **All screens** - Every screen adapts to theme

## Troubleshooting

### If theme doesn't switch:
1. Make sure you're tapping the theme buttons in Settings
2. Try navigating to another screen and back
3. Restart the app if needed

### If colors look wrong:
- Dark mode should be **dim dark blue**, not pure black
- Text should be clearly readable in both modes
- Cards should be slightly lighter than background in dark mode

## Next Steps

Once you've tested the theme switching:
1. Use the app in both light and dark modes
2. Check if all text is readable
3. Verify all screens look good in both themes
4. Let me know if you find any issues!
